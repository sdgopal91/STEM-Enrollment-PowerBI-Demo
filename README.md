# STEM-Enrollment-PowerBI-Demo
This Power BI dashboard analyzes public school enrollment in mathematics and science courses across U.S. states using 2013–14 Civil Rights Data Collection data published through Data.gov. The goal of the project was to evaluate course enrollment patterns, compare participation across STEM subjects, and create an executive-style reporting dashboard that highlights trends by state, course category, and student group.
The dashboard was designed as a portfolio project to demonstrate end-to-end data analytics skills, including data cleaning, Power Query transformation, data modeling, DAX measure development, dashboard design, KPI reporting, and insight communication.
